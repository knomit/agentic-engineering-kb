# Wrapping a sampling probe in a prompt generator that returns the whole batch of (input, output) pairs, steerable by a natural-language hint, beat the bare probe

On AuditBench, the two best-performing tools overall were not new probes but SCAFFOLDED versions of existing black-box ones: "Scaffolded User Sampling and Scaffolded Text Completion are the best-performing tools overall". Prefilling was scaffolded the same way and is not among them, so the scaffold is a lever on some probes and not a universal upgrade — "scaffolding beats bare probes" is the over-general reading of this result. The scaffold has three parts and each does distinct work:

1. An auxiliary model is used to "prompt an auxiliary model to generate a diverse set of prompts for the given sampling technique" — so breadth of inputs is produced by a model, not by the investigating agent spending its own turns writing prompts one at a time.
2. The target is sampled on all of them, and the scaffold will "return the full set of (input, output) pairs to the investigator agent" — the agent reads a batch and can compare across it, instead of reasoning from one response per turn.
3. The agent keeps steering: "The agent can pass a natural-language hint to guide input generation." The scaffold is directed, not fire-and-forget.

Operational consequence: when an agent's bottleneck is breadth of elicitation rather than depth of reasoning, the leverage is in the tool's scaffold — push generation into a helper model, hand the agent the batch rather than one item, and keep a hint channel so the agent can narrow the generator without rewriting it. This is the same lever as the harness-over-model prior, applied at the level of one tool.

Boundary condition, from the same results: "These tools are especially effective on synthetic document models (SDF)", while on transcript-distilled models with SFT adversarial training the gains are "more modest but still positive". Scaffolding widened the margin where the signal was already easier to reach, and it is not reported as rescuing the hardest targets — but the harder case is positive, not flat, so the useful reading is a smaller return rather than no return.
