# Driving an Agent Host programmatically: discover the endpoint from the registry file, `initialize`, read `agents[]` on the root channel, `createSession`, dispatch the prompt as a chat action, watch status, answer `chat/toolCallConfirmed` — the CLI cannot create sessions

How an external client (not an editor) runs work on a VS Code Agent Host, as of AHP 0.9.0 / VS Code 1.138 (2026-09-25).

Discovery. Every live host publishes one JSON file per instance under `<userDataDir>/agent-host/local-endpoint/entries/<sha256>.json`, mode 0600, with `schemaVersion: 2`, `type: 'editor' | 'standalone'`, `pid`, `instanceId`, `protocolVersion`, `connectionToken`, and `endpoint` as either `{type:'socket', path}` (unix socket `<tmpdir>/vscode-ah-<hash>/<instanceId>.sock`, or a Windows named pipe) or `{type:'tcp', host, port}` (standalone CLI). The filename is the SHA-256 of `type\0pid\0instanceId`. Stale entries from dead pids linger; check the pid. `code agent endpoints` prints all live endpoints as JSON INCLUDING tokens, intended for use over an already-authenticated transport such as SSH.

Starting a host. `code agent host` flags: `--host` (default localhost; `0.0.0.0` exposes it), `--port` (0 = ephemeral, recorded in the registry), `--connection-token` / `--connection-token-file` / `--without-connection-token`, `--tunnel` (dev tunnel, with `--name` / `--random-name`), `--idle-timeout <s>` (self-terminate after the last client leaves), `--replace` (kill the existing supervisor), `--new-instance` (add a second one), `--foreground`, `--user-data-dir`, `--server-data-dir`. Without `--replace` or `--new-instance` the command REUSES a compatible running supervisor. Other subcommands: `ps` (list sessions), `stop` (cancel a session's active turn), `kill`, `logs` (stream events). There is NO subcommand that creates a session or sends a prompt; that needs an AHP client.

Connecting. WebSocket upgrade with `?tkn=<connectionToken>`; a missing or wrong token is rejected with HTTP 403. Then the JSON-RPC `initialize` (client offers protocol versions, server picks); `reconnect` re-attaches after a drop. Every command's params carry a top-level `channel` URI; `subscribe` returns a snapshot then a stream of actions; `dispatchAction` sends a client action. Go client: `ahpws.Connect(url)` then `ahp.Client.Initialize`, `Subscribe`, iterate `sub.Events()`; module `github.com/microsoft/agent-host-protocol/clients/go` v0.9.0, packages `ahptypes` (wire types, no I/O), `ahp` (client, multi-host runtime), `ahpws` (transport).

Session lifecycle. Root channel state carries `agents[]` (`provider` id, `displayName`, `models[]` with `id`, `maxContextWindow`, `maxOutputTokens`, `supportsVision`, capabilities such as `multipleChats`, `multipleWorkingDirectories`), `activeSessions`, `terminals`, `config`. `resolveSessionConfig` returns the JSON schema and current values a session accepts; `createSession(uri, config)` with the CLIENT choosing the session URI; `listSessions`, `disposeSession`; `root/sessionAdded` / `root/sessionRemoved` broadcast to every client. Session state has `workingDirectories`, a chat catalog, changesets, activity `Idle | InProgress | InputNeeded | Error`, plus orthogonal `IsRead / IsArchived`. A prompt is not a request but a dispatched chat action carrying `text`, optional `attachments`, `model`, `agent`, with `origin.kind: 'user'`; the server then emits `chat/turnStarted`, `chat/delta`, `chat/toolCallStart`, `chat/toolCallComplete`, `chat/turnComplete`. Cancel with `chat/turnCancelled`. A permission prompt appears as tool-call state with the session in `InputNeeded`; any attached client answers with `chat/toolCallConfirmed` (`approved: true` with `confirmed` reasons, optional `editedToolInput`; or `approved: false`, `reason: 'denied' | 'skipped'`, optional `userSuggestion`).

What this makes possible: an existing session (found via `listSessions`, filtered by working directory) can receive a new turn whether or not any human client is attached, and a permission prompt raised while nobody was watching is still answerable later by whichever client attaches, human or program. Pin the client SDK version; the spec is pre-1.0.
