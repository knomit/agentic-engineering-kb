# Long-running agents need snapshot-and-resume, and container-level isolation cannot provide it

Cognition's stated reason for building on microVMs rather than containers is not primarily security — it is that real engineering work has ASYNC GAPS. An agent that "waits on CI, responds to code review, reruns tests, and pushes a follow-up commit" faces gaps between each step of "minutes, hours, sometimes days". Without snapshotting, an agent can only survive an async break by burning compute to stay alive, and "if the container is rescheduled, times out, or crashes, the session is lost."

Their solution is "snapshotting full machine state at the hypervisor level — memory, process trees, and filesystem", so a session can shut down entirely while idle and resume exactly where it left off. They report this as the single most time-intensive piece of infrastructure they built, on top of a year of hypervisor engineering for the microVM layer itself.

The design consequence worth carrying: if your agent workload has any waiting-on-external-systems step, the runtime question is not "how do I isolate this" but "how do I suspend and resume this," and those two requirements pick different substrates. A container platform answers the first and not the second.

The security argument is separate and also stated: "Containerized agents share a kernel, which means one compromised session can access every other container's filesystems, credentials, and network connections" — which matters specifically because agents execute untrusted model-authored code.

They also name orchestration, governance, and integrations as three interdependent systems that all have to exist at scale. "Our solution for the orchestration layer took over three quarters of dedicated engineering", and they report a cautionary case: "A leading cloud data platform company we spoke with attempted this and ultimately moved on after the project scope overwhelmed their infrastructure team." Read that as the build-versus-buy signal it is — and note it is a vendor making the case for its own product.

Headline customer result, vendor-reported and uncontrolled: "Itaú, the largest private bank in Latin America, is eleven months in with nearly 17,000 engineers — and has completed migrations 5 to 6x faster, auto-remediated 70% of static-analysis security vulnerabilities, and increased test coverage by 2x."
