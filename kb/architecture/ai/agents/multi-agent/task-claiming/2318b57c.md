# A 16-agent write fleet coordinated through claim files in the repo, not through a message bus — and the whole run cost just under $20,000 for 100,000 lines

Sixteen agents wrote one compiler concurrently with no orchestrator process and no inter-agent messaging. Mutual exclusion was a file in the repository: an agent claimed a unit of work by "writing a text file to current_tasks/" — the report's example is "current_tasks/parse_if_statement.txt". Each agent ran in its own containerised environment, cloned to /workspace, and pushed to upstream. Collisions were expected rather than prevented: "Merge conflicts are frequent, but Claude is smart enough to figure that out."

Why the shape matters: the coordination state lives in the same artifact the work lives in, so it survives every session boundary, needs no running coordinator, and is inspectable by a human with `ls`. An orchestrator process would have had to stay up for two weeks and would have become the single point of failure for sixteen workers.

Some agents were given standing roles rather than units — "coalescing any duplicate code", "improving the performance of the compiler itself", "outputting efficient compiled code", and documentation. These are the janitorial functions a fleet with no shared context stops doing for itself.

THE COST ENVELOPE, which is the part most worth carrying into a build-or-not decision: "Nearly 2,000 Claude Code sessions" over "two weeks", "2 billion input tokens" and "140 million output tokens", "a total cost just under $20,000", producing a "100,000-line compiler" that reaches "99% pass rate on most compiler test suites" and compiles Linux 6.9 on x86, ARM and RISC-V. Note the input-to-output ratio of roughly 14:1 — a write fleet's bill is dominated by re-reading context, not by generating code, so cache economics decide whether this is affordable.

WHAT THE RESULT IS NOT. The report states the compiler lacks efficient code generation and 16-bit x86 support, and that the fleet "frequently broke existing functionality" when adding features. A 99% suite pass rate on a 100,000-line artifact coexisted with continuous regression; a claim file gives exclusivity on a unit of work and no protection against one agent's change breaking another's finished unit. Budget for a regression-catching role, not only for feature units. The conditions under which fanning out writes pays at all are at [[kb/decisions/ai/agents/multi-agent/parallel-writes/71be00f9]].
