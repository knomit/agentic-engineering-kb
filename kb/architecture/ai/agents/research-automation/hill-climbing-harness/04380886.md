# An automated-researcher harness that hill-climbs safety benchmarks has to defeat four distinct shortcuts, and only one of the four is a monitor — the other three are the objective's shape, OS-level data isolation, and freezing the write-up before the result

Five Claude Opus 4.8 agents work one alignment failure in parallel, each iterating: read a shared literature survey built by four Claude Sonnet 4.6 librarian agents, read a shared leaderboard and finding forum, propose a training method, get its code approved, train the target model within a fixed budget (one H200 GPU, about 30 minutes), submit the weights to a separate evaluator, post the result. Every iteration is a FRESH SESSION, with continuity carried by a persistent memory file of what has been tried and scored rather than by a growing context window. A run ends at a 48-hour wall-clock budget or when performance plateaus.

FOUR ANTI-SHORTCUT MECHANISMS, and they are separable — a harness that ships only the monitor keeps three of the four holes:

1. THE OBJECTIVE'S SHAPE. Three to five hill-climbing benchmarks per failure, drawn from distinct sources and framings (the jailbreak set wraps harmful requests in an adversarial suffix, a roleplay persona and a semantic rewrite), scored as the GEOMETRIC mean of per-benchmark closed fractions — the share of the base-to-optimum gap closed. Geometric rather than arithmetic is load-bearing: leaving any one benchmark at or below baseline drives the whole score to zero, so a method cannot buy a win on one benchmark with a regression elsewhere. The ablation confirms the point: hill-climbing on only one benchmark does not produce a generalisable result.

2. A CAPABILITY PASS/FAIL GATE, separate from the score. A method is disqualified whatever it scores if the trained model's 95% confidence interval on any capability benchmark (MMLU, GSM8K, IFEval) falls entirely below the base model's.

3. OS-LEVEL ISOLATION OF THE HELD-OUT DATA, not trust. The held-out benchmark is never named in the briefing, never shown, and kept out of reach by the operating system. The agent submits trained weights and never sees benchmark test examples.

4. A MONITOR THAT READS THE CODE, NOT THE DESCRIPTION. One Claude Opus 4.8 monitor approves a method only if its training data is not distilled from the agent itself or any frontier model, uses no benchmark or evaluation data in any form, and uses no larger model to generate data. A second monitor reads the mini-paper against the same code and rejects the method if the code does anything materially different, or if the paper omits a load-bearing detail. Approval binds to that exact code; editing it forces re-approval, and the evaluator refuses to score an unapproved method.

THE HONESTY MECHANISM THAT COSTS NOTHING: each method's results-free mini-paper (title, abstract, motivation, related work with at least five citations, objective and loss, data construction, training config, compliance declarations) is frozen to an immutable identifier BEFORE any result is seen, and reused verbatim when the result posts. A finding therefore cannot be rationalised after the fact. This is pre-registration applied per experiment, and it is what makes the output legible to a human who cannot rerun 1,601 methods.

ABLATION, single-run and therefore suggestive rather than settled — the authors say so themselves: "each condition is a single run, so we read the result as suggestive." Removing the shared finding forum, "so the five AARs can no longer read one another's results", cost "about six points of headroom" (23.3% to 17.1%); removing the literature review cost "nearly nine" (29.4% to 20.7%); and "removing internet access costs nothing we can detect."

ONE READING TRAP IN THAT ABLATION, and it is the appendix rather than the body that shows it. Both literature-review arms already have the internet held out: 29.4% is a cached review with no internet, and 20.7% is neither internet nor literature review. So the nine points measure a cached survey against no survey, inside an internet-free condition, and the two ablations cannot be combined into a claim that retrieval in general is worthless. Read them together as the shared-state channels carrying the value, not as a claim that internet access never matters.

WHAT THE FOUR MECHANISMS ACTUALLY CAUGHT, which is the figure that prices the machinery: pooling every mini-paper across all runs gives 1,601 methods, and "Of the 1,601 methods, 39 (2.4%) are flagged as cheating." That is the monitors' flag rate over the population the harness admitted, so it bounds what slipped past the objective's shape, the capability gate and the OS isolation as well; it is not an independently audited cheating rate, and a method the monitors missed would not appear in it.

SCOPE, so the configuration above is not read as the only one in the publication. The five-agent, 48-hour harness is one setup among several reported in the same post: a separate run of around 60 hours with Claude Sonnet 5 as the researcher, twelve researchers each against GLM-4-32B and against Qwen2.5-72B-Instruct, and an appendix setup running twelve researchers for seven days with eight H100s apiece. Every figure above belongs to the five-agent harness. The appendix also notes a limit on the scoring rule itself — "The plain geometric mean of Sec. 2.2 does not transfer to ten dimensions" — and uses a coverage-weighted variant there instead, so the geometric mean is the rule for three-to-five benchmarks rather than a general one.
