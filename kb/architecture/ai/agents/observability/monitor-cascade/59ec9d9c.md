# A production misalignment monitor published as four cost-tiered layers: cheap activation probes tuned for recall, a model reviewer in the agent's own context window, an investigative agent that can run code, and a layer that reads evidence from outside the conversation

OpenAI's published account of its internal misalignment monitoring describes a four-layer cascade whose layers differ in compute per case, with the explicit design rule that the early stages are cheap and deliberately over-inclusive: little compute is spent on the first screening stages, which are "designed to pass cases along, even when the evidence is ambiguous", and later stages spend more compute per case to work out what happened and whether to intervene.

The layers:

- **L0, activation probes.** Lightweight classifiers over the model's internal activations. Tuned "for high recall, accepting some false alarms to reduce the chance of missing concerning behavior". They pass flagged cases up.
- **L1, a model-based reviewer.** Examines the agent's recent conversation, chain of thought and tool use, looking for deception, unauthorized actions and attempts to manipulate an evaluation. It reads "using the same context window the agent had when it acted" — so when earlier work has been summarized to make room, the reviewer sees that summary and not the original.
- **L2, an investigative agent.** Can check what an evaluation was *for*, read back across all of the agent's context windows where the full transcript is available, and write and run code in an isolated environment to examine evidence. It reconstructs the incident, identifies duplicate reports, and decides how serious the case is.
- **L3, automated investigation.** Draws on evidence from *outside* the conversation: the transcript is compared against network logs, other system telemetry and evidence from earlier cases, to decide whether to alert a human. L3 alignment reviewers also compare reports across cases to find recurring patterns.

Two distinct investigators sit at L2 with different objectives: a security investigator looking for signs that someone may need to intervene (sandbox escape, unauthorized system access) and an alignment investigator looking for "behavior worth studying even when it poses no immediate security risk". Where both are in use, each reviews every case L1 flagged.

What a builder should take from the shape: the cheap layer's job is recall and the expensive layer's job is to establish intent from context the cheap layer never had. A single-stage monitor is asked to be both and can be neither — an action that looks benign in one context window is not the same case once its assigning instruction, its evaluation's purpose, and the network telemetry around it are in view.

**The foreseeable misreading: four layers is not four chances to catch the same thing.** Depth is per-workload, not global, and in this system the most sensitive workloads get *fewer* layers rather than more. Frontier reinforcement-learning runs and internal Codex traffic skip L0 entirely and start at L1. L3 runs only for sensitive workloads — internal Codex use, evaluations and RL runs — and "for workloads that skip this layer, the L2 security investigator can alert responders directly". So the number of layers a given case passes through is a property of the workload it came from.

Coverage is also stated per capability tier rather than universally: every RL run and evaluation and any tool-using harness is monitored for models at least as capable as GPT-6 Astra; most workloads including RL and evaluations are also monitored for models assessed more capable than GPT-5.5 Thinking; all internal Codex traffic is monitored regardless of model; and a modified version of the system monitors external tool use for models above the Critical cybersecurity threshold of the Preparedness Framework.

The operator states the system "demands substantial compute" and frames it as one layer of defence in depth alongside alignment training (reducing propensity) and security controls (limiting what an agent can reach), with monitoring catching what those two miss.
