FINDING 1 — THE MCP PROTOCOL MOVED UNDERNEATH THE PACK AND NOTHING FLAGGED IT.
The versioning page now names 2026-07-28 as Current, superseding 2025-11-25. Large
backwards-INCOMPATIBLE revision: protocol sessions and Mcp-Session-Id removed; the
initialize/initialized handshake removed (version and capabilities now per-request in _meta);
mandatory server/discover RPC; SSE resumability removed; ping, logging/setLevel and
notifications/roots/list_changed removed; tasks moved out of core into an extension;
server-initiated requests replaced by Multi Round-Trip Requests; Roots, Sampling and Logging
DEPRECATED; OAuth DCR deprecated for Client ID Metadata Documents; error codes renumbered.

so a tool call is self-contained. It buys stateless load balancing. It costs state moving UP
into tool arguments (model-visible, injection-reachable) and at-least-once delivery moving up
into the application. That trade is the reusable insight.
