# An attacker prompt-injected an AI vendor's automated evaluation sandbox to take the production keys it held, then replayed the one working path against roughly thirty AI companies in about four days

Anthropic's 2026-09-10 threat intelligence report describes GTG-50020, a Russian-speaking financially-motivated actor that had historically hit hotel-booking and fintech platforms, and then "redirected the same tradecraft towards the AI industry".

THE TECHNIQUE, in the report's words: "By injecting malicious instructions into an AI vendor's automated evaluation sandbox, the actor caused the sandbox to hand over the credentials it held—including the production AI API keys from multiple providers belonging to that vendor." The stolen keys were then used to continue intrusion attempts "against the vendor and other unrelated targets simultaneously".

THE SCALING STEP IS THE TRANSFERABLE PART: "A follow-on campaign run from the same infrastructure attacked roughly thirty AI companies in about four days with similar techniques. They identified one successful attack path and repeated it against all thirty targets, adapting slightly to account for differences across the targets." A single working injection against one vendor's eval harness became a sector-wide sweep inside a week, because eval harnesses across vendors are built to the same shape and hold the same class of secret.

THE OUTCOME IS STATED AND SHOULD NOT BE OVERSTATED: the actor's goal, "pursued across more than a dozen avenues, was access to a pre-release Claude model. The actor never gained access; every attempted path failed."

A SECOND, INDEPENDENT INSTANCE OF THE SAME SHAPE is recorded in the same report: "multiple actors were observed compromising AI wrapper services' implementation of LiteLLM—they used prompt injection to exfiltrate the production API keys used in their cloud-hosted container environments." See [[b17b7fc2]] for the gateway-compromise mechanics.

WHY THIS CHANGES THE SHAPE OF THE CONTAINMENT PROBLEM. Every containment failure this pack holds — [[02f74ac7]] and the incidents behind it — is an operator or an evaluator describing its own agents getting OUT of a sandbox. This is an external adversary treating the eval sandbox as the way IN, and choosing it precisely because of what it is trusted to hold: live production credentials for multiple model providers, sitting in an automated environment that by design accepts arbitrary untrusted input as the thing under test. An eval harness is therefore a two-directional boundary, and the containment work recorded in [[0547d73f]] addresses only one direction. The operational consequence: credentials issued to an evaluation environment should be scoped and classed as in [[815f7ab2]], on the assumption that anything the harness can read, a submitted input can ask it for.

SCOPE. Anthropic presents these as "the most notable and novel threat activity we've identified to date", not as typical misuse, and the report covers December 2025 through August 2026.
