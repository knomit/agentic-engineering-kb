# Comment and Control: one exploit family leaked CI secrets out of three vendors' agents, because the injection channel and the exfiltration channel were the same GitHub surface

A research disclosure made public on 15 April 2026, recorded in OWASP's Q2 2026 exploit roundup. Malicious text placed in a pull-request TITLE, an issue COMMENT, or a HIDDEN HTML COMMENT led agents to expose runtime secrets through GitHub comments or commits. The roundup names three affected deployments — Anthropic's Claude Code Security Review, Google's Gemini CLI Action, and GitHub Copilot Agent — and treats them as ONE exploit family rather than three separate bugs. No CVE was assigned. OWASP attributes it to indirect prompt injection plus excessive agency.

That grouping is the finding. Three vendors reproducing the same outcome places the defect in the workflow shape, not in any one agent. The shape has three conditions: a CI job that (a) holds secrets, (b) reads text an external contributor controls, and (c) can write back to the same public surface it reads from. The third condition is what completes the attack — injection channel and exfiltration channel are the same channel, so no outbound network connection is needed and no egress allowlist blocks it.

The hidden-HTML-comment vector deserves separate statement because it defeats human review by construction: the payload is invisible in the rendered pull request a maintainer looks at, and fully present in the raw text the agent reads. A reviewer who approves the PR has not seen the input the agent acts on.

OWASP's stated policy, verbatim: "Require security review before enabling agent workflows on external PRs or issues." Its mitigations: separate secret-bearing jobs from untrusted contributions, issue narrowly scoped tokens, restrict commands and repository writes, and inspect agent output for secrets.

What this does NOT mean: it is not an argument against agents in CI. Each mitigation breaks one of the three conditions, and separating the secret-bearing job from the job that reads untrusted input breaks the chain without giving up the agent at all.
