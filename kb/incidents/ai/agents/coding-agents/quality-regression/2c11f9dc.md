# Claude Code's April 2026 regression: three unrelated harness changes, no model change, and a cache bug that showed up as usage limits draining early

Between early March and late April 2026, Claude Code users reported the agent felt "less intelligent," citing forgetfulness, repetition and odd tool choices. The API was unaffected, which localised the fault to the harness. Anthropic's postmortem names three independent causes, none of them a model change.

1. Reasoning-effort default lowered from `high` to `medium` (March 4 – April 7) to cut latency. Internal evals had measured this correctly — "slightly lower intelligence with significantly less latency" — and the team shipped it anyway. Users rejected the trade. Reverted, and the default is now `xhigh` for Opus 4.7 and `high` elsewhere. The lesson is that an eval can be accurate and the decision still wrong, because the eval does not encode the user's exchange rate between latency and intelligence.

2. A prompt-caching bug (March 26 – April 10). The intent was to clear cached reasoning once after an hour of session idle, to cut resume latency. The `clear_thinking_20251015` header with `keep:1` instead cleared thinking on every turn for the rest of the session, so each request dropped the previous reasoning blocks and memory loss compounded turn over turn. Fixed in v2.1.101. Two things generalise: dropping reasoning blocks mid-session invalidates the prefix cache, so the SECOND observable symptom was usage limits draining faster than expected — meaning an unexplained cost or quota anomaly is a usable detector for a context-management bug, and the cost signal may be the sharper of the two. It also took over a week to root-cause because two unrelated concurrent experiments masked it in testing.

3. The ≤25/≤100-word verbosity instruction (April 16 – April 20), measured at a 3% ablation drop.

The compounding observation: reports began in early March but were "challenging to distinguish from normal variation," and neither internal usage nor evals initially reproduced any of it. Three separate small regressions overlapping in time is what made the signal unreadable — the same overlap pathology as Anthropic's September 2025 infrastructure postmortem. Their process changes were per-model evals for all system-prompt changes, soak periods and gradual rollouts for anything intelligence-affecting, and gating model-specific changes to their target models.
