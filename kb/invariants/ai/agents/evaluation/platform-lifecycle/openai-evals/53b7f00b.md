# OpenAI's Evals platform, its graders and reusable prompt objects are all scheduled to shut down on 2026-11-30, and the Evals platform has been read-only since 2026-10-31 — the guidance pages for them are still live

Three withdrawal notices sit on three separate OpenAI documentation pages, all naming the same end date, and all three pages still read as current guidance.

FROM THE PAGES, read 2026-11-09. The evaluation guidance page: "OpenAI is deprecating the Evals platform", "Evals will become read-only for existing users on October 31, 2026", "and the platform is scheduled to shut down on November 30, 2026." The graders reference page: "OpenAI is deprecating graders as part of the evals and fine-tuning workflows they support." The text-generation guide: "OpenAI is deprecating reusable prompt objects in the API ... v1/prompts is scheduled to shut down on November 30, 2026."

CONSEQUENCE. Anything built on the hosted Evals platform, its grader JSON, or server-side prompt objects needs a migration target rather than a schedule slot, and the read-only date has already passed, so an existing suite cannot be extended in place. The transferable content of those pages — grader semantics, judge-calibration order, the failure-as-zero behaviour of the grader runtime — survives as design knowledge about scoring systems in general; the API surface does not.

WHAT THIS DOES NOT MEAN. The withdrawal is of these hosted products, not of evaluation support generally: the same documentation tree continues to carry agent-evaluation guidance under its own paths. Nor does a deprecation notice establish a replacement — none of the three pages names a successor product in the text read.

STATUS. These are stated schedules, not observed shutdowns, read from the vendor's own pages before the dates arrive.
