# Skill instructions arrive at user-prompt priority, so a skill is not a policy layer — the rule you move into SKILL.md gains no authority by being there

OpenAI's skills guide states the injection point plainly: "Skill instructions are user prompt input (not system prompt input)," "so they're handled with the same priority as other user-provided instructions."

Consequence for design: a rule you move into a SKILL.md does not gain authority by living there. It competes on equal footing with everything else that arrived in the user turn — including text the agent pulled from a document, a web page, or a tool result. A skill is the right home for procedure, format and accumulated gotchas. It is the wrong home for the one constraint that must hold even when the input argues against it; that belongs wherever the harness grants system-level priority, or in code that runs outside the model's control.

The same guide pairs this with three handling rules that follow from it: "Any Skill should be reviewed as potentially untrusted input until validated by the developer"; do not expose an open skills catalogue to end users, but map skills to specific workflows so end users cannot select arbitrary ones; and gate write or high-impact actions behind explicit approval and policy checks regardless of what a skill says.

Invocation is model-decided, and the guide's stated route to more deterministic behaviour is to tell the model explicitly to use a named skill. So a skill is also not evidence that a procedure ran.

What this does NOT mean: priority is not progressive disclosure, and this does not weaken [[e9b7eef3]]'s point that the description is the entire selection surface. A skill's content can be both lazily loaded and low-priority once loaded; those are independent properties, and the second is the one nobody checks.

Scope: stated by OpenAI for its own platform. It is not established that every Agent Skills implementation injects at user-prompt priority — the bundle format is an open standard, but the injection point is each harness's choice — so verify it on the harness you ship on rather than carrying this across.
