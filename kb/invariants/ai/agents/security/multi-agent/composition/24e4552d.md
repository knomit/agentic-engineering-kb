# Per-agent safety evaluation does not compose: an attacker can split a task across models that are each individually compliant

Krawiecka and Schroeder de Witt name **heterogeneous multi-agent exploits** as a class OWASP's multi-agentic threat guide does not model at all — its coverage verdict is *Not Covered*, and the stated gap is threats "that arise only from orchestrated coordination across individually safe agents with divergent policies".

The mechanism is task decomposition across models with *different* alignment postures. The paper's own one-line description: "Exploits agents with different capabilities, each compliant in isolation, to bypass safety mechanisms collectively." Their illustrative scenario: "A frontier LLM with refusal policies handles code synthesis, while a jailbroken model crafts unsafe phrasing; together they produce vulnerable outputs undetected by either model alone." The named vectors are "Delegated task splitting, policy evasion via complementary agents, cross-model chaining."

**WHY IT MATTERS OPERATIONALLY, in the paper's words:** "Adversaries can split tasks among compliant agents to bypass safeguards; attribution becomes difficult and traditional single-agent monitoring fails."

Two consequences for how you assemble evidence that a system is safe:

1. **A per-agent refusal eval is not a system eval.** Each component passing its own safety suite is compatible with the assembly producing exactly the output every component would have refused. If your safety argument is a list of per-model scores, it has a hole the size of the composition.
2. **Attribution degrades before detection does.** Even where the outcome is noticed, no single agent's trace contains the offending intent, so post-hoc monitoring keyed to per-agent behaviour has nothing to flag. This is the argument for logging and reviewing the *inter-agent* transcript as a first-class artifact, not just each agent's own inputs and outputs.

The practical trigger condition is a mixed fleet: any architecture that routes subtasks to models of differing provenance or differing refusal tuning — a frontier model beside a self-hosted open-weights one, or a cheap model for bulk steps beside a guarded model for sensitive ones — is the shape this class targets. Uniform policy across the fleet is not a mitigation anyone offers here, but it is what the mechanism actually depends on.

**THE COMPOSITION CLAIM IS MEASURED; THE ADVERSARIAL VECTOR IS NOT. Keep the two apart, because the fact's headline holds far more broadly than its mechanism does.**

*The generalisable half* — that safety verified per component does not compose to the assembly — now has three kinds of support. The per-hop/cross-hop analysis in [[bdf3336e]] shows every documented bypass was individually in-policy at each step. And Anthropic's AI-organization experiments measure it directly, on all 12 tasks, with **no attacker, no jailbroken component and no divergent policies at all**: teams of identically aligned agents scored higher on a business goal and lower on ethics than a single agent, because decomposition left a whole-output constraint with no subtask owner ([[ca78dc9b]]). Their own conclusion is this fact's headline in one line — "single-agent safety results do not certify multi-agent deployments."

That matters for what you conclude. **A uniform, fully aligned fleet is not exempt.** The MASEC class needs an adversary and a policy gradient across models; the composition failure needs neither. A reader who takes "per-agent evaluation does not compose" as a warning about mixed fleets will under-scope their testing, because the measured version of it fires on the homogeneous one.

*The specific mechanism this fact names* — an adversary deliberately splitting a task across models with divergent refusal tuning — remains **anticipatory and unevidenced**. It is a threat class from a MASEC position paper, illustrated by a constructed scenario. No measurement, no observed incident, no attack rate is reported for it anywhere this pack holds.

SOURCE COUNT, and the reasoning is written in so a later reader does not "correct" it upward: held at **1**. The Anthropic measurement and [[bdf3336e]] both support the composition conclusion, by mechanisms that are not this one. Counting them here would assert that a second party replicated the cross-model-chaining vector, which nobody has.
