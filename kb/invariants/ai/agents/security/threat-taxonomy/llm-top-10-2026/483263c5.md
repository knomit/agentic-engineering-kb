# OWASP LLM Top 10 2026 (published 2026-08-03): Excessive Agency climbed to third, System Prompt Leakage became Hidden Context Exposure, and there is now an explicit hand-off rule to the Agentic list

The 2026 edition supersedes the 2025 list. If you are working from LLM01:2025..LLM10:2025 identifiers, they have moved.

**THE 2026 LIST, verbatim from the contents page:**
- LLM01:2026 Prompt Injection
- LLM02:2026 Sensitive Information Disclosure
- LLM03:2026 Excessive Agency
- LLM04:2026 Supply Chain
- LLM05:2026 Data and Model Poisoning
- LLM06:2026 Unbounded Consumption
- LLM07:2026 Misinformation
- LLM08:2026 Hidden Context Exposure
- LLM09:2026 Vector and Embedding Weaknesses
- LLM10:2026 Improper Output Handling

**THE MOVES OWASP CALLS OUT, in its own words.** "Excessive Agency climbed to third, the most consequential move on the list, because the vote and the record agree that agentic deployments are where the damage is landing." "Unbounded Consumption rose four places." "Improper Output Handling fell the furthest, from fifth to tenth." Misinformation moved up from LLM09:2025 to LLM07:2026. Prompt Injection held first and Sensitive Information Disclosure held second.

**ONE ENTRY WAS RE-SCOPED, NOT RENUMBERED.** "What used to be System Prompt Leakage is now Hidden Context Exposure, a broader framework for the same failure to trust information that should have stayed out of reach." The widening matters if you scoped a control to "don't leak the system prompt": LLM08:2026 enumerates disclosed rules or logic enabling more targeted injection, embedded credentials, revealed tool permissions and schemas expanding the excessive-agency surface, and leaked output-formatting rules facilitating improper output handling. Tool schemas and permissions are hidden context too.

**FOUR ENTRIES ABSORBED NEW RISKS RATHER THAN SPAWNING NEW CATEGORIES** — deliberately, because "standing up thin new categories would have splintered the list for no gain": Prompt Injection now covers cross-modal attacks that hide instructions inside an image or audio track; Supply Chain now covers the trust failure when a promoted model artifact is not what it claims to be; Data and Model Poisoning absorbs fine-tuning subversion; Improper Output Handling now spans insecure code that assistants generate at scale.

**THE HAND-OFF RULE, which is the part most useful to an agent builder.** OWASP now states the boundary explicitly: "This list owns the risk when the model is a component inside your application. The moment that model becomes an actor, with tools it can call, memory it carries between sessions, and consequences it sets in motion downstream, the risk moves to the OWASP Agentic Top 10." The three named triggers — callable tools, cross-session memory, downstream consequences — are a usable test for which list applies. And the lists are not alternatives: "Read an entry here for the model-as-component failure. When your model starts acting on its own, pair it with the Agentic list, because neither one covers that ground alone."

Appendix A carries coverage matrices to OWASP Agentic Top 10 (ASI) 2026, OWASP GenAI Data Security 2026 (DSGAI) v1.0, MITRE ATLAS v2026.06, MITRE ATT&CK v19.1, CWE 4.20, NIST AI 600-1, NIST AI RMF, CSA AICM v1.1 and OWASP AIVSS v0.8 — so the mapping work between frameworks is already done and does not need redoing by hand.
