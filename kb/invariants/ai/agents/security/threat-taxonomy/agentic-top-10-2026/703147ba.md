# OWASP Top 10 for Agentic Applications 2026 (ASI01-ASI10), read from the primary document — with the T-taxonomy mapping and the T12 name collision that will bite anyone who follows it

Read from the primary PDF (labelled "Version 2026", dated December 2025; Agentic Top 10 Chair John Sotiropoulos, Lead Keren Katz, Co-lead Ron F. Del Rosario). Earlier facts in this pack described this list from SECONDARY documents — the December 2025 announcement post and the AIUC-1 crosswalk. This is the document itself.

**The ten entries, verbatim from the contents page:**
- ASI01: Agent Goal Hijack
- ASI02: Tool Misuse and Exploitation
- ASI03: Identity and Privilege Abuse
- ASI04: Agentic Supply Chain Vulnerabilities
- ASI05: Unexpected Code Execution (RCE)
- ASI06: Memory & Context Poisoning
- ASI07: Insecure Inter-Agent Communication
- ASI08: Cascading Failures
- ASI09: Human-Agent Trust Exploitation
- ASI10: Rogue Agents

**Mapping to the T-numbered "Agentic AI — Threats and Mitigations" taxonomy**, which the document states remains the foundational taxonomy this Top 10 relies upon rather than replacing:
- ASI01 -> T06 Goal Manipulation + T07 Misaligned & Deceptive Behaviors
- ASI02 -> T2 Tool Misuse (with T4 Resource Overload and T16 Insecure Inter-Agent Protocol Abuse as contributing factors)
- ASI03 -> T3 Privilege Compromise (the document calls this one-to-one); AIVSS Core Risk 2, Agent Access Control Violation
- ASI04 -> T17 Supply Chain Compromise, spanning T2, T11, T12, T13, T16
- ASI05 -> T11 Unexpected RCE and Code Attacks
- ASI06 -> T1 Memory Poisoning (related: T4 Memory Overload, T6 Broken Goals, T12)
- ASI07 -> T12 + T16 Insecure Inter-Agent Protocol Abuse
- ASI08 -> T5 Cascading Hallucination Attacks (T8 Repudiation and Untraceability named as the fundamental defense)
- ASI09 -> T7 Misaligned & Deceptive Behaviors
- ASI10 -> T13 Rogue Agents in Multi-Agent Systems

*** THE TRAP: T12 IS GIVEN TWO DIFFERENT NAMES IN THIS DOCUMENT. ***
Under ASI06 and in the Appendix A matrix it is "T12 Shared Memory Poisoning"; under ASI04, ASI07 and elsewhere in the same matrix it is "T12 Agent Communication Poisoning". These are not the same threat — one is stored-state corruption, the other is in-flight message corruption — and the collision appears in the mapping table itself, so a reader building an ASI-to-T crosswalk from this document will produce a contradiction. This fact does NOT resolve which name is correct: settle it against the Agentic AI — Threats and Mitigations guide directly, not against this Top 10. Flagged because the two ASI entries involved (ASI06 and ASI07) are precisely the pair the document elsewhere works hard to keep distinct.

A second, smaller inconsistency: the Appendix D incidents tracker labels ASI01 "Agent Behaviour Hijack" once, against "Agent Goal Hijack" everywhere else. One occurrence, almost certainly a stale draft name; noted so it is not mistaken for an eleventh category.

**"Least-Agency"** is the document's own coinage, presented as an extension of Least-Privilege and of Excessive Agency: avoid unnecessary autonomy, because "deploying agentic behavior where it is not needed expands the attack surface without adding value". Operationally it appears under ASI02 as per-tool least-privilege profiles — scopes, maximum rate, egress allowlists — with the concrete instruction to express them as IAM or authorization policy stanzas attached to each tool "rather than relying on ad-hoc conventions".

Structure of each entry, useful when citing: Description, Common Examples of the Vulnerability, Example Attack Scenarios, Prevention and Mitigation Guidelines, References. Appendices: A Agentic AI Security Mapping Matrix, B relationship to OWASP CycloneDX and AIBOM, C mapping to the Non-Human Identities Top 10 (2025), D the ASI Agentic Exploits & Incidents Tracker, E abbreviations.
