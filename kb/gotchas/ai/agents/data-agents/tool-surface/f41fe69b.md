# The two changes that improved OpenAI's internal data agent were subtractive: the full tool set was cut back for overlapping functionality, and prescriptive step-by-step prompting was replaced with high-level goals

OpenAI's internal analytics agent — "Our agent is powered by GPT-5.2 and is designed to reason over OpenAI's data platform", a platform that "serves more than 3.5k internal users working across Engineering, Product, and Research" and spans "over 600 petabytes of data across 70k datasets" — reports two changes that helped, and both removed something.

First, the tool surface: "Early on, we exposed our full tool set to the agent, and quickly ran into problems with overlapping functionality." The fix was to restrict and consolidate the tool calls. Note the stated cause is overlap specifically, not count — two tools that could each plausibly serve a request is the condition, and a large set of clearly disjoint tools is not the same situation.

Second, the prompt: "We also discovered that highly prescriptive prompting degraded results." Prompting moved from prescriptive steps to high-level goals.

Scope: self-reported operational experience on an internal-only tool, with no before-and-after measurement published for either change. Treat both as a direction to try on an agent that is selecting the wrong tool or over-constrained, not as a quantified result.
