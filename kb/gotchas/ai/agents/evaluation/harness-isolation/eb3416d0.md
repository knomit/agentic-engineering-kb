# Eval trials that share state produce correlated failures that look like model regressions

Anthropic names shared state between trials as a distinct eval failure mode: leftover files, cached data, and resource exhaustion carry from one trial into the next, producing failures that are correlated with each other and unrelated to agent performance. The symptom is a run where later trials degrade, or where a suite's score shifts between runs with no model or prompt change — and the natural but wrong reading is that the model regressed.

Each trial needs a fresh environment, not merely a fresh conversation. This is the eval-harness analogue of test pollution, and it is easy to miss because the agent under test is the thing that dirties the environment: it writes files, installs packages, and consumes quota as a normal part of doing the task.

The closely related trap is stochastic tasks — tasks whose environment cannot be reproduced exactly from run to run. These produce an unreliable signal regardless of how good the grader is, so either pin the environment or exclude the task.

This compounds with the separately measured finding that agentic coding eval scores move several points on CPU and RAM allocation alone: between infrastructure noise and trial contamination, a large share of apparent score movement in agent evals is not the agent.
