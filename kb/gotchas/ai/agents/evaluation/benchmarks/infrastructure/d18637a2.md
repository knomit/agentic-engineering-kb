# Agentic coding eval scores move ~6 points on CPU and RAM allocation alone — treat sub-3-point leaderboard gaps as noise

Anthropic ran Terminal-Bench 2.0 across six resource configurations holding model, harness, and task set constant, and found a 6 percentage point spread between the most- and least-resourced setups (p < 0.01). SWE-bench moved 1.54 points at 5x baseline RAM. Infrastructure error rates fell from 5.8% under strict enforcement to 0.5% uncapped.

The mechanism splits at 3x headroom, and the split is what makes this actionable. Below 3x, the 2.1-point gain (p=0.40) was reliability noise — transient resource spikes killing runs that would otherwise have passed. Above 3x, the gain is real capability: with headroom the agent can actually invoke heavyweight tools and install large dependencies that resource limits were silently blocking. So under-resourcing an agentic eval does not just add variance, it removes strategies from the agent's reach and reads as model incapability.

The consumer rule they state: treat leaderboard differences below 3 percentage points with skepticism unless configuration is documented and matched. This is a sharper and more specific version of the general problem that the same model scores differently across eval harnesses — here the HARNESS IS IDENTICAL and only the container's resource limits differ.

If you run agentic evals: specify guaranteed allocation and the hard kill threshold as two SEPARATE numbers rather than pinning them to the same value (floor = ceiling is the strict-enforcement configuration that produced the 5.8% error rate), calibrate the gap until score differences fall within noise of each other, report the enforcement methodology alongside the score, and run at multiple times on multiple days — they also observed time-of-day API latency and cluster health as unquantified confounders.

The implication for your own agent's evals is the one most people miss: a regression you are attributing to a prompt or model change may be your CI runner being busier this week.
