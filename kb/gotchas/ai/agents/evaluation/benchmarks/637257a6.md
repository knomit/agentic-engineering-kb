# tau-bench's pass^k exposes inconsistency that pass^1 hides

tau-bench (Sierra) evaluates agents in simulated multi-turn conversations with a language-model-simulated user, domain API tools, and written policy guidelines, across retail and airline domains. Its distinctive metric is pass^k — the probability that ALL k independent trials of the same task succeed. This is the opposite of the more familiar pass@k (succeeding at least once in k tries), and the difference matters: pass@k measures potential, pass^k measures reliability.

The published numbers show how much single-shot scores flatter agents. Claude 3.5 Sonnet (Oct 2024): retail pass^1 0.692 falling to pass^4 0.462; airline pass^1 0.460 falling to pass^4 0.225. GPT-4o: retail 0.604 → 0.383; airline 0.420 → 0.200.

Read that as: an agent that handles a retail task about 70% of the time handles it four times running only about 46% of the time. The variance is not noise around a competence level — it is inconsistent policy adherence, the agent following the written rules on one run and not the next.

The design consequence: a headline pass^1 number tells you almost nothing about what a user with repeat interactions will experience. If you are shipping an agent that touches the same customer more than once, measure repeated-trial consistency yourself, and note the airline domain — more policy constraints — degrades harder than retail, so rule density is a risk factor.

STALENESS (checked 2026-07-26): the absolute numbers above are superseded. A successor benchmark, tau2-bench, exists as of 2026 with additional domains (including telecom and voice) and a much larger model field, and reported frontier scores are far higher than the 2024 figures here. Treat the specific values as a historical snapshot and re-derive current ones from the live leaderboard before quoting them. What has NOT changed, and is why this fact is kept: the pass^1-versus-pass^k gap as a measurement technique, and the point that consistency is a separate axis from capability which single-shot scoring hides.
