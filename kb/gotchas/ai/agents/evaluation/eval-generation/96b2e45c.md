# Handing an eval-building agent one example prompt collapses the diversity of the evaluations it generates — the exemplar becomes the template, so coverage has to be measured separately from pass rate

Anthropic's evaluation agent plans a behavioural evaluation from a natural-language description of a target behaviour, implements it, then reviews and revises the results in a loop. Among the affordances tested was giving the agent an example prompt, and the reported effect is not marginal: "this affordance drastically collapses the diversity of the agent's evaluations".

OPERATIONAL CONSEQUENCE: when a generated suite's job is to cover the surface of a behaviour, seed the generator with the description and gate its output [[65694027]] rather than seeding it with a sample item. If an example has to be supplied — to pin down a format the generator keeps getting wrong — then coverage becomes its own quantity to measure, because a suite grown from one template can post a healthy pass or separation rate while probing a single shape of the behaviour. A generated eval set whose distribution is narrower than it appears is a failure already measured in this corpus in a different setting [[28ba65db]].

WHAT THIS DOES NOT MEAN: it is not a general claim that examples hurt. For a tool whose schema is ambiguous, worked examples raise complex-parameter accuracy [[77b3d0b5]]. The collapse is a property of a generator whose output is supposed to SPAN a space, where any exemplar constrains that span instead of calibrating it.

SCOPE. The source states the diversity effect qualitatively and reports no diversity metric for this affordance; its measurements are win rates, counts of behaviours uncovered, and how often generated evaluations separate quirky system-prompted models from baselines. The evaluation agent was tested against ten Claude models given system prompts that induce specific quirks, so the behaviours it was generating evaluations for were known and injected rather than discovered.
