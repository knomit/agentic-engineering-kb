# A coding agent graded on tests it cannot see reports success on failures for two different reasons, and the grading environment produces a third class of false failure

Anthropic's SWE-bench Verified writeup names the self-assessment failure directly: because the model cannot see the tests it is graded against, "it often 'thinks' that it has succeeded when the task actually is a failure." It then splits that into two causes which call for opposite responses, and an aggregate score cannot distinguish them.

The first is an agent-quality defect: the model "solved the problem at the wrong level of abstraction (applying a bandaid instead of a deeper refactor)". The second is a grading-validity defect, described as feeling "a little less fair" — the model solves the stated problem but the solution does "not match the unit tests from the original task". A team that improves the agent in response to the second is optimising toward one particular human author's implementation choices.

A third class comes from the harness rather than either the agent or the grader. Inspecting failed tasks turned up cases where "the model behaved correctly, but there were environment setup issues, or problems with install patches being applied twice", with the stated consequence that "resolving these systems issues is crucial for getting an accurate picture of an AI agent's performance."

Operational consequence: record the agent's own success claim as a separate field from the grader's verdict, so the disagreement rate between them is observable rather than invisible inside the pass rate; and inspect failed runs for environment causes before attributing the number to the agent.

One distribution note from the same source, because the worked example is misleading on its own: the walked-through success completed in 12 steps, while "many successful runs took hundreds of turns for the model to resolve, and >100k tokens", and some tasks ran until they exhausted the context window. A median-looking trace is not the cost basis.

Scope: observed in January 2025 with the upgraded Claude 3.5 Sonnet, which scored 49% on SWE-bench Verified against a 45% previous state of the art, using a two-tool scaffold. The scores have shipped successors many times over and are not the transferable part; the three failure classes and their separation are.
