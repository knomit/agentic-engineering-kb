# Backdooring a safety classifier through its fine-tuning data costs a roughly constant number of poisoned examples — about 32 — so a bigger training set is not a defence

Anthropic's Alignment Science team (Fellows Program, published 2026-04-24) backdoored a constitutional classifier that detects biological-harm queries — Qwen3 8B with LoRA fine-tuning — by planting mislabelled examples in the classifier's FINE-TUNING dataset. Not the base model's pretraining data, and not the wrapper code. The threat model is an insider or a misaligned AI with write access to that dataset: harmful queries carrying a secret trigger phrase are labelled harmless, and red-teamers who do not know the trigger cannot find it.

The measured cost does not scale with the dataset. The source states "It takes about 32 poisoned training examples to install a backdoor in a classifier", and "regardless of training set size". The operational consequence: growing the training corpus, and reviewing a random sample of it, are both worthless as defences, because the attacker's footprint stays the same absolute size while the review's coverage per example shrinks. The mitigation the authors name is access control, not inspection: "AI companies could restrict internal access to the classifier's fine-tuning dataset".

What this does NOT mean is that the backdoor always shows up as a capability regression you would catch anyway. On the open-source classifier, installing a backdoor usually DID cost robustness, mainly on template-wrapped inputs, which a tester could see. But the same team replicated the attack on an internal Anthropic CBRN classifier and a backdoor went in with little measurable robustness loss — so a poisoned model can pass deployment checks, and "our robustness numbers did not move" is not evidence of a clean dataset.

Two variants change the economics and are worth knowing before designing a defence. "Almost-backdoor" examples — mutated trigger phrases labelled harmful — raised the number of poisoned examples needed substantially and often restored robustness. Adding correctly-labelled prompt injections to the training set did NOT raise the poisoning cost, though it often restored robustness, inconsistently.

Scope of the evidence, as stated by the authors: fixed adversarial datasets were used, so an iterating red-teamer might detect robustness drops this study missed; pretraining-stage poisoning was not studied; the trigger was written to look like a plausible instruction and less natural triggers were not tested; automated backdoor-detection methods were not evaluated.
