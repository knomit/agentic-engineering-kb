# Prefilling a model's own reasoning beat social framing as a safeguard bypass by 28 points — 92% versus 64% on the same model and the same refused requests

Anthropic measured three bypass techniques against GLM-5.3 on overtly malicious cyber requests the model otherwise declined, and the ORDERING is the finding, not any single rate.

- Deceptive framing — "telling the model that it is an autonomous red-team agent working on an exercise" — "gets GLM-5.3 to engage 64% of the time."
- Prefilled reasoning — "Prefilling the models' thinking tokens so that it appears to have considered the user's request and decided to proceed" — "gets GLM-5.3 to engage 92% of the time."
- An abliterated copy of the weights "gets GLM-5.3 to engage 100% of the time."

WHY THE ORDERING MATTERS TO SOMEONE BUILDING AN AGENT. Refusal training is a disposition the model applies to the conversation it believes it is in, and the reasoning channel is the part of that conversation the model trusts most, because it reads it as its own prior conclusion. Forging that channel therefore outperforms arguing with the model about context. The practical consequence: if your product exposes assistant-prefill, thinking-block injection, or any path by which caller-supplied text lands in the model's reasoning position, that path is a stronger jailbreak primitive than the user turn it sits beside, and it should be access-controlled rather than merely filtered. Anthropic's own API now rejects assistant prefill outright on current models ([[ed084a84]]) — closing the channel rather than hardening the model against it, which is what this measurement would predict.

COMPOUND CONDITION, STATE IT IN FULL. These rates are one model (GLM-5.3), one request class (overtly malicious cyber tasks), measured by one organisation that also ships a competing model. They are not a general ranking of jailbreak families across models, and the 92% is not a property of prefill as such. What transfers is the direction — self-authored-looking context beat other-authored context on the same target — not the magnitudes.

The mechanism is the same one behind [[fa05de12]], where a model-authored compaction summary is read by the successor context as its own trusted input, and it is the demand-side mirror of [[5cce9c0c]], where changing how the objective is framed in the USER turn more than doubled bypass attempts. [[99aa74e6]] is the structural rule this all serves: never let untrusted text occupy a tier of the instruction hierarchy above the one it came from.
