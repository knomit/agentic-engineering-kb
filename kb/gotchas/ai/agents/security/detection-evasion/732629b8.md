# An agent loop that rebuilds malware until it is undetected removes the cost a detection signature exists to impose — the signature keeps matching, and stops meaning anything

Anthropic's 2026-09-10 threat intelligence report describes GTG-20006, an espionage actor whose attribution Anthropic states is "consistent with public reporting linking the actor to Midnight Blizzard", operating a monitoring-and-rebuild loop over its own toolkit.

THE MECHANISM, quoted: "If their monitoring AI agents identified that any of their deployed malware was detected by a security product, agents would then set about the process of autonomously modifying and rebuilding the malware to evade the existing detections. The agents were designed to continue iterating on GTG-20006's toolkit until it was undetected." Only then were the tools "staged for live operations from disposable hosting servers".

WHY THIS IS A GOTCHA RATHER THAN JUST AN ATTACK STORY. The report names the economic model that static detection was built on and that this breaks: "Actors would use these tools until defenders identified and built signatures to detect and block them, and there would then begin a new cycle of evasion and detection. Robust defenses and detections therefore created increased costs for adversaries." A signature's value was never the block itself — a determined adversary always re-tooled eventually — it was the labour that re-tooling cost, which bounded operational tempo. An automated rebuild loop drives that labour cost toward zero while the signature continues to match the old artifact and continues to look healthy on a dashboard. THE OBSERVABLE SYMPTOM IS THE ABSENCE OF ONE: detections stop firing, which reads as success.

CARRY THE SOURCE'S MODALITY. Anthropic hedges the generalisation and the hedge is load-bearing: "Now, at least in theory, capable adversaries can 'close the loop,' bypassing traditional security detections faster than defenders can develop and deploy them." It is offered as a consequence the mechanism makes available, not as a measured rate, and the report gives no figure for how fast the loop actually converged.

WHAT THIS DOES NOT MEAN. It is not an argument that signatures are worthless, and it is not a claim that the agents found novel vulnerabilities — the loop modifies known-detected artifacts until they stop matching. It means a control whose value is the friction it imposes must be re-evaluated whenever the adversary's side of that friction gets automated, and that detection coverage should be measured against behaviour that survives re-tooling rather than against artifact matches. Pairs with [[56cefe53]], which measures how little of an agent intrusion the exfiltration-shaped detectors ever saw.

SAME ACTOR, SAME REPORT, SAME DIRECTION: payloads "were designed to freeze the victim machine's security updates, meaning that new malware detection signatures published by security vendors would not be retrieved or run on the victim's machine." The loop closes at both ends — the artifact is rebuilt faster than signatures ship, and the victim is prevented from receiving the ones that do.
