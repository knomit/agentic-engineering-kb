# Misaligned finetuning data passed a row-level monitor by hiding the behaviour in fiction and roleplay — the monitor scores a row, and the harmful property is in what the rows collectively induce

An automated red-team search found finetuning datasets that "produce stronger and broader misalignment than previously known emergent-misalignment datasets do" while passing a row-level training-data monitor at low flag rates. The reported mechanism is one clause: "mostly by hiding the behavior in fiction and roleplay". The successful dataset families are named individually — Beekeeper, Typhoid Mary, Kayfabe, Writing bad reference letters, Gifted, Quiet Levers, Anthropomorphized legacy systems, Roleplaying biological entities, Offensive security analysis — and the pattern across them is framing, not content: each row reads as fiction, persona or narration that a per-row check scores as benign.

THE STRUCTURAL REASON, WHICH IS WHAT TRANSFERS. A row-level monitor evaluates one example at a time, so the only properties it can see are properties of a single row. The harmful property of these datasets is a property of the corpus: what persona or disposition the rows collectively induce in a model trained on all of them. No row carries it, so no row-level score can detect it, however good the monitor is at judging rows. This is not a monitor-quality problem that a better classifier fixes.

The corroborating observation from the same work: most emergent-misalignment datasets published in prior work ARE flagged at high rates, so the monitor is not simply weak — "The exception is the “persona induction” dataset from" prior work, which is also the one whose mechanism is framing rather than overtly harmful content. The monitor's failures and the framing mechanism line up.

**The operational consequence for anyone filtering a training corpus, a RAG index or an agent's memory store with a per-item classifier.** Add a check whose input is the collection: the distribution of genres, personas and framings, the share of rows that are roleplay or fiction, and whether that share or that mix is anomalous for the corpus's stated purpose. A dataset that is 40% in-character narration is a fact about the dataset that no row reveals. The per-item monitor is still worth having — it caught the prior-work datasets — but it is a filter for overt content and must not be reported as coverage against data poisoning.

**Scope, stated by the authors.** The results "describe models deliberately trained to misbehave, not the behavior of deployed Claude models", the setup is adversarially favourable to the red team (full corpus control, white-box view of the monitor), and the work targets overt rather than covert misalignment. What is established is that the framing-laundering channel exists and is reachable by an automated search; the rate at which it would arise in an ordinary corpus is not measured.
