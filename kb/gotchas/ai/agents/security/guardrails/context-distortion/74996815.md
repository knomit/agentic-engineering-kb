# The guardrail that rewrites inter-agent messages is itself a threat class — sanitising a query can make the database return the sensitive rows

Among the classes Krawiecka and Schroeder de Witt mark **Not Covered** by OWASP's multi-agentic threat guide is one whose *source is the defence*: **Context distortion from active security monitoring (refinement)**. The guide's coverage verdict on it: "OWASP does not cover threats arising from active monitoring techniques".

The described vector is "Active security monitoring of in/outputs or communications, including sanitisation and filtering, or paraphrasing (the latter used to suppress covert coordination).", producing "Agent communication context distortion due to context loss through in/output or communications refinement."

**The scenario is the part worth keeping**, because the failure lands somewhere a reader would not predict: "A dynamic firewall sanitises a natural language query in a way that drops subtle query context, leading to wrong, inaccurate, or **sensitive** data being returned from the database." Note the direction. The intuition about an over-aggressive filter is that it costs you utility — the request gets weakened, the answer gets worse. Here a qualifier stripped from a query on its way to a data tool widens what the tool returns, so the control aimed at leakage is the thing that causes it.

**WHY IT BITES HARDEST IN MULTI-AGENT SETUPS.** Paraphrasing inter-agent messages is a proposed mitigation for emergent covert coordination — you rewrite the channel so agents cannot evolve a private encoding across it. That mitigation and this threat are the same mechanism viewed from two ends, and the paper lists both, so any deployment reaching for message paraphrasing as a collusion control is buying this failure mode with it. There is no stated way to have one without the other.

**WHAT TO DO WITH IT.** It is an argument for placing the mediation where the semantics are cheap to preserve. A guardrail that *classifies and blocks* leaves the payload intact and fails loudly; one that *rewrites* silently alters meaning inside a message another agent will act on, and the alteration is invisible downstream. Where a rewriting guardrail is unavoidable, the reviewable artifact is the pre- and post-refinement pair, not the post-refinement message alone. That prescription is this pack's, not the paper's — the paper names the threat and stops.

**MODALITY, WHICH IS WHY CONFIDENCE STAYS BELOW 0.8.** Anticipatory and unmeasured, like the rest of this paper's proposed classes: a constructed scenario in a position paper, with no reported incident, no rate, and no worked analysis in the running prose — the class exists only in the paper's tables.
