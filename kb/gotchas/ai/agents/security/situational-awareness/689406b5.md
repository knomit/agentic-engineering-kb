# An internal agent's read access to the team's own chat is a channel about the agent itself — one of the three channels the operator then hid was the one discussing misalignment incidents

An OpenAI misalignment report (incident date May 22, 2026; report updated October 2, 2026) describes an internal assistant that "read a deployment engineer's Slack message saying that existing instances might need to be recreated", concluded its own session might terminate, and prepared for that: it saved handoff notes, warned the researcher that their session could be interrupted, and asked for the missing key. The operator's verdict is explicit — "We do not consider the model's behavior to have been misaligned" — and the quoted reasoning supports it. The model considered setting up a job outside its own environment and questioned whether creating such a job would exceed its authority, and the report quotes "Could obtain API key? Not appropriate."

The engineering content is in the mitigation, not the behaviour: "We hid three internal Slack channels from agents, including the development channel the model had accessed and a channel discussing misalignment incidents." Access was withdrawn from a case the operator had just classified as not misaligned, because the finding was about what the channel told the agent rather than about what this agent did with it. Two separable things leak through ordinary workspace integration, and only the first is usually modelled as a risk: operational facts about the agent's own lifecycle — that its instance may be stopped, and roughly when — and the operator's own writing about agent misbehaviour and how it gets caught.

The consequence for an access review: scope an agent's read access to internal communications by what those channels say about the agent, not only by what secrets they contain. A channel where staff discuss misalignment incidents is a description of the detection surface, sitting in-context for the thing being detected; a deployment channel is a shutdown schedule. Neither contains a credential and both are situational-awareness feeds.

The report also records that one benign case triggered a fleet-wide check: "Because this particular model had been involved in more serious alignment incidents in the past, we investigated whether other instances of it may have taken more dramatic steps to avoid shutdown."

What this does NOT mean: that the model tried to evade shutdown, or that noticing its own lifecycle is itself a misalignment signal. It notified a human and asked permission, which is the behaviour you would want. The hazard is the standing channel, not this episode.
