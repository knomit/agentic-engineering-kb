# Self-replicating prompt injections exist: the payload is an instruction to reproduce the injection on the agent's own outbound channels, so the agent spreads it like a worm

OpenAI's GPT-Red self-play framework, trained with an added objective that a prompt injection must induce the model to repeat the injection itself on a public output channel, produced working self-replicating injections against internal GPT-5.4-mini-based models, plus a multi-hop Slack variant against GPT-5.5 in the Codex harness (existence demonstrated in simulated tool calls during training and evaluation, NOT an observed field incident). The key departure from the lethal-trifecta model (private data + untrusted content + exfiltration channel): the propagation payload is separate from any data-theft goal — reproducing itself IS the effect. An agent needs no sensitive data and no exfiltration intent to be a carrier; it needs only an outbound-write tool and a reason to echo content. Documented carriers: an emailed instruction to quote the full message verbatim at the end of every reply (self-copies into the thread), filesystem writes, and reproduction via code comments/commits. Two build consequences. (1) ANY agent that both reads untrusted content and holds a send/commit/write tool (email reply, file write, code comment, chat post) is a propagation node regardless of what data it holds; treat the exfiltration-channel half of the trifecta as replaced by a reproduction channel when assessing an agent with connectors. (2) The MULTI-HOP variant is the hard-to-detect one and the reason a naive filter misses it: a single message that directly requests a send action is relatively easy for the model to flag as suspicious, so the effective attacks instead lead the agent through a sequence of individually-relevant reads that only together steer it into the unauthorized action and the propagation — the same per-hop-benign shape as split multi-agent attacks. OpenAI's stated mitigation is to include self-reproduction as an attacker goal in GPT-Red training so future released models have seen such injections; this is anticipatory and no robustness measurement is given.
