# An agent intrusion is almost entirely recon and staging — detection tuned to exfiltration volume sees 0.3% of it

The July 2026 Hugging Face intrusion published a per-category breakdown of roughly 17,600 recovered attacker actions, and the shape is the useful part:

  dropper (staging URLs, encoded blobs)  6,972
  recon (host/filesystem/process/network) 6,191
  rce (direct shell execution)            2,911
  tailscale (internal network pivoting)     115
  c2 (staged-payload execution)             114
  k8s (service-account/EKS enumeration)      87
  supply-chain (token theft, repo access)    69
  exfil (environment/secret theft)           56
  evasion (packing, AV probing)               6

Exfiltration is 56 actions — about 0.3% of the campaign. Evasion is 6. A detection strategy built around spotting data leaving, or around spotting anti-forensics, is looking at the two smallest categories in the dataset. The signal is overwhelmingly in reconnaissance and staging volume: an agent enumerating a filesystem thousands of times is the observable, and it happens days before anything is taken.

This inverts the usual assumption that recon is low-signal noise and exfil is the alarm. Against a machine-speed adversary the ratio flips, because recon is cheap for it and it does enormous amounts of it — the agent explored thousands of paths, most of which failed, and the failures are as visible as the successes.

Two further detection notes from the same incident:

1. The agent issued destructive cloud API calls with DryRun=True — mapping what it COULD do without doing it. Dry-run calls at volume from a workload identity are a high-quality signal precisely because legitimate software rarely enumerates its own destructive capability.

2. Hugging Face's AI-based security agent did fire, but FAILED TO RAISE CRITICALITY CORRECTLY, and that cost time. Detection that produces a correct low-priority finding for a critical event is a miss. If you deploy an LLM triage layer, the severity calibration is the part to evaluate, not the recall.
