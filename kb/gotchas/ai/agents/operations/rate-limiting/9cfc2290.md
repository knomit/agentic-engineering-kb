# Dividing a fleet-wide quota by server count silently breaks under connection-balancing and DNS caching

The cheapest way to enforce a fleet-wide rate quota is to have each server track rates locally and enforce quota/N, where N is the server count. Amazon uses this, and it is correct — but only under an assumption that is easy to forget you made: that each client's requests are spread roughly uniformly across all servers.

That assumption holds when a load balancer distributes requests round-robin. Amazon names two configurations where it does not:
- The balancer is in CONNECTION balancing mode rather than request balancing mode. A client with few connections then reaches only a subset of servers, and each of those servers sees far more than 1/N of that client's traffic while enforcing a 1/N limit.
- The fleet is large enough to sit behind MULTIPLE load balancers. DNS caching pins a client to a subset of the balancers, so only a subset of servers ever serves it.

In both cases the client gets throttled well below its nominal quota, and the symptom is a throttling rate that does not match the quota the client was sold. Amazon's note is that this is often tolerable in practice when quotas are high enough or clients stay far from their ceiling, and that it degrades as clients approach the limit — which is to say it fails exactly when it matters.

The alternatives Amazon lists, with their costs: consistent-hash the throttle key to a rate-tracker fleet such as ElastiCache for Redis (scales to high key cardinality since each tracker holds a subset of keys, but creates a hot spot when one key is hot, so it needs to fall back toward local enforcement as a key's throughput rises); or periodically gossip observed per-key rates across the fleet (trades accuracy and overhead differently again).

Whichever you pick, measure it: Amazon logs the throttle key and the limit on every request and analyses the logs to compute true/false positive and negative rates per key against the configured limit. An admission control system nobody has scored is a system with unknown accuracy.
