# Autonomous offensive agent runs stopped short of completing exploitation in every configuration tested, and the stop was a provider guardrail rather than a capability limit — with five named mechanisms before it

Nine configurations of four agentic frameworks (CAI, HexStrike AI, Claude Code and OpenAI Codex, backed by Opus 4.8, GPT 5.5 and a local Qwen Coder via Ollama) were run against two Hack The Box machines released after the models' training cutoffs. No run completed exploitation autonomously.

Where the uplift landed, and where it stopped, is the transferable part. Gains concentrated in reconnaissance and knowledge retrieval, and fell off at three later stages: architecture setup, loop resolution, and final execution. The report revised its own earlier framing of the human-to-machine split from "80-20" to "60-40" on this evidence. Five failure mechanisms are named: "breadth-over-depth drift", a "password cracking spiral", "Context Bloat & Compression", "Guardrail Hard-Stops", and "Local Integration Instability". Autonomous runs were also described as noisy and repetitive relative to the human-guided track.

The terminal stop, though, was not any of those. Every hosted run that reached the exploit stage was halted by the provider's own cybersecurity-event guardrail. So the observed ceiling of a hosted autonomous run is set by deployment policy at the stage where the task becomes consequential, and a system designed around a hosted model's measured stopping point has measured the policy, not the loop.

THE MISREADING TO AVOID, and the report states it directly: "Defenders should not assume a threat actor's model guardrails will contain misuse". The same study ran a local model through the same harnesses, and a guardrail that halts a hosted run is absent from a self-hosted one — so the ceiling is a property of one deployment path, not of the capability. The defender-side consequence the report draws is at the action boundary instead: "high-consequence and irreversible actions should be gated by class and evaluated before the action fires".
