# Manager agents assume they share state with their children, and are overly prescriptive when they lack codebase depth

Running a manager agent that spawns child agents (Cognition does this via an internal MCP server), two failure modes show up that are not obvious from the architecture diagram:

1. "Agents assume they share state with their children when they don't." The manager writes instructions as if the child can see what the manager has seen, and the child receives a message that silently presupposes missing context. This is not a prompt-quality problem you can fix by telling the manager to be thorough — Cognition attributes it to models not having been trained in environments where cross-agent communication was required, so it does not happen by default.

2. "Managers trained on small-scoped delegation default to being overly prescriptive, which backfires when the manager lacks deep codebase context." Read the causal structure carefully, because it is easy to invert. The prescriptiveness comes from TRAINING — models learned delegation on small, well-understood scopes, where spelling out HOW is correct. Shallow codebase context is not what causes the verbosity; it is what turns the verbosity harmful, because a detailed instruction set built on a wrong mental model of the terrain overrides the child's ability to discover the right approach.

The practical consequences for anything built on a manager-child topology:

- State transfer must be explicit and mechanical. Do not rely on the manager to notice what the child is missing; it will not, by default.
- Give a manager the same codebase-exploration budget as a worker before letting it decompose. Note what this does and does NOT buy: more context does not make the manager less prescriptive, because prescriptiveness is a trained default — it makes the prescriptions less wrong. If you also want less prescription, that has to be asked for directly in the manager's prompt, and it is a separate intervention.

See also the related cost failure where models over-delegate rather than under-delegate; the two compound, because over-delegation multiplies the number of children receiving under-specified state.
