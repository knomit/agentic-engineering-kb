# Naively generated eval queries do not look like real user queries — steer generation with context and filter documents first

Chroma's generative benchmarking work measures the gap between synthetic eval queries and the real thing, which matters because building a retrieval eval from LLM-generated questions is the default shortcut.

The failure: naive generation produces queries that echo the source document's own wording. On Wikipedia Multilingual (en), 11.91% of naively generated query pairs sat above 0.9 cosine similarity to each other, and naive queries averaged 0.716 query-document similarity against 0.628 for deliberately distinct generation. High similarity to the document is not a good thing here — it makes retrieval look easy in a way real queries never are, because real users do not phrase questions in the document's vocabulary.

What fixes it is a two-stage method: (1) filter the document set with an LLM judge aligned on three explicit criteria — relevance, completeness, intent — and (2) generate queries with contextual steering plus example real queries so the output matches the production phrasing distribution. Measured on Weights & Biases production data, context-guided generation reached KL divergence of 0.159 against the true query distribution versus 0.207 for naive, and Recall@10 of 0.530-0.679 which brackets ground truth's 0.439-0.670.

The number to internalise about the judge: aligning the document-filtering judge with human labels took 5 iterations to move agreement from 46% to 75.2%. A judge you have not iterated on is close to a coin flip on this task.

One finding that limits the damage: relative rankings of embedding models were CONSISTENT between ground-truth and generated queries. So synthetic benchmarks are usable for CHOOSING between retrievers even when their absolute numbers are inflated — just never quote the absolute recall as an expected production figure.

Stated limitations: the real-data validation rests on a single dataset, the metrics do not capture queries that have no matching document at all, and the LLM judges showed high sensitivity to minor prompt changes.
