# Audit a benchmark with model investigators AND several human reviewers per task, because the two modalities miss different defect classes and the agent pipeline is the conservative one

OpenAI's audit of a coding benchmark ran three stages, and the published comparison between them is the useful part, not the pipeline itself.

The stages: (1) an automated screen that reads the prompt, the model attempts, the failure traces and the grading tests, and flags candidates; (2) Codex-based investigator agents that run several independent repeats per flagged task with repository and test access, with a researcher making the final call; (3) a human campaign in which "Each task was reviewed by five engineers", judging the prompt, tests and gold patch BEFORE seeing the pipeline's output, assigning a label and severity and escalating disagreements.

What the comparison showed. The two modalities agreed on the headline — both found roughly a third of tasks broken — but not on which defect each task had: "reviewers' judgments overlapped in 74% of cases". The disagreement had a direction. Humans assigned multiple labels more often, so the agent pipeline was CONSERVATIVE and undercounted tasks with overlapping defects. The clearest divergence was low-coverage tests, the top human-selected issue at 9.4% of tasks against 4.1% from the agent pipeline — that is, the agents were weakest at spotting the defect class that inflates scores rather than deflating them.

The operational consequence, in order: use strong models to scale inspection across prompts, tests, patches and traces, because that is the only way to cover a whole benchmark; but keep a human pass with more than one reviewer per task and blind it to the pipeline's output, because an agent-only audit reports a floor on the defect rate, not the rate. If you must pick one defect class to re-check by hand, pick the one where partial work passes.

What this does NOT mean: the 74% figure is reviewer-versus-agent-category overlap on flagged tasks, not an inter-rater agreement statistic among the humans, and the post publishes neither inter-rater statistics nor the sampling rule behind the audit. Do not cite it as evidence that the human labelling here was reliable.
