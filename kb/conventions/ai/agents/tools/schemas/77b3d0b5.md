# Tool `input_examples` lift complex-parameter accuracy from 72% to 90% — worth it only where the schema is ambiguous

Anthropic's Tool Use Examples feature adds an `input_examples` field to a tool definition holding concrete sample invocations, rather than describing usage in prose. On their complex-parameter-handling evaluation this moved accuracy from 72% to 90%.

What examples convey that a JSON Schema cannot: format conventions (how a date or ID is actually written), correlations between parameters (when A is set, B must be too), and how to populate deeply nested structures.

Use `input_examples` when the tool has complex nested structures whose usage is ambiguous from the schema alone, when it has many optional parameters and which ones you include actually matters, and when several sibling tools are similar enough to need disambiguation. Skip it for simple single-parameter tools with obvious usage and for standard formats the model already handles — there the examples are pure context cost.

This pairs with the general rule that tool descriptions compete with their siblings: examples are the cheapest way to encode a distinguishing usage pattern that prose descriptions tend to blur.
