# Budget tool responses in tokens: cap, paginate, and offer a concise mode

Tool results are the largest uncontrolled consumer of an agent's context, so treat response size as a designed parameter rather than whatever the API returns. Anthropic's specifics: Claude Code caps tool responses at 25,000 tokens by default. Tools should ship pagination, range selection, filtering, or truncation with sensible defaults already set — not as opt-in parameters the model must think to use.

When you truncate, the truncation notice is a prompt: say what to do instead ("narrow your query"), not merely that output was cut. A bare "...truncated" teaches the model nothing and it will re-issue the same broad call.

Offering a ResponseFormat enum of "concise" vs "detailed" is cheap and large: in their Slack example the concise form cost ~72 tokens against ~206 for detailed, roughly a third. Give the model the choice rather than picking one globally, since the same tool serves both scanning and drill-down.
