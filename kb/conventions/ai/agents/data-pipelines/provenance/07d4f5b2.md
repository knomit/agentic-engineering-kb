# An agent pipeline that fills gaps must label every output element measured or predicted, and earn its error bar by predicting data it was told to hide

The agent-built UV sky map had no ground truth over a large part of its own output: "Roughly a third of the sky has never been observed in UV." Two practices are what make the published artifact usable rather than merely complete.

First, a hold-out self-test. The author had the agent hide parts of regions where UV data does exist, predict them, and compare against the withheld values; "it was able to estimate the hidden data to within about 10% of the real UV measurements". The gap model predicted UV from visible, infrared and radio observations rather than interpolating from UV alone, so the hold-out tests a cross-band regression rather than smoothing.

Second, provenance inside the deliverable. The output "label[s] each pixel as \"measured\" or \"predicted\"" and carries per-point uncertainty estimates, so a consumer can restrict an analysis to observed values without re-deriving which ones those are.

Operational consequence: whenever an agent produces a dataset that mixes observation with inference — enriched records, imputed fields, synthesized rows, extrapolated series — the deliverable is three things, not one: the values, a per-element measured/inferred flag, and an uncertainty. The accuracy claim comes from masking data you hold and predicting it back. Without the flag, downstream consumers cannot tell which rows they are entitled to trust and will treat the whole table as observed. Without the masked hold-out, the uncertainty is asserted rather than measured.

Boundary condition on the figure: the hold-out regions are parts of regions that otherwise have UV coverage, so their neighbourhoods carry measurements the never-observed areas do not. The source reports the hold-out error; it reports no validated error for the unobserved third, so the ~10% figure is an interpolation result and must not be quoted as the map's error everywhere.

Also reported on the same project: the first pass was not the deliverable — the team produced more than a dozen successive versions.
