# The intern test: decide between more context, decomposition, and debugging

A diagnostic for a task an agent is failing at. Ask: could a relevant college student, given the same inputs, complete this task — and how long would it take them?

- If NO, they could not do it with these inputs → the problem is context. Enrich what the agent is given. More prompting will not conjure information that is absent.
- If YES but it would take them a long time → the problem is scope. Decompose the task into steps.
- If YES and quickly → context and scope are fine, so the problem is in your pipeline. Go look at the failure traces.

The value is that it separates three fixes that look identical from the outside — an agent producing a wrong answer gives no signal about which one it needs, and teams default to prompt-tweaking regardless of which of the three is actually broken.
