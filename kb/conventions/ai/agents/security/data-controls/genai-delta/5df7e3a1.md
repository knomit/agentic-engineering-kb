# Six familiar control families each need one specific extension for GenAI, and the extension is the part a generic security program leaves out — retrieval-time ACLs, derived-surface encryption, least-logging, per-integration trust zones, agent egress control and unlearning readiness

An OWASP GenAI Security Project playbook sets out a traditional-versus-GenAI control table, and its value is that each row keeps the familiar control and names the one thing that has to be added. The additions, in the document's own words:

Encryption: "Add encryption for embeddings, KV caches, agent memory, and tool-call payloads." The derived artefacts, not the source data, are what a conventional at-rest programme misses.

Identity and access: non-human identities — agents, MCP servers, tools — get "JIT credential minting and zero-standing-privilege", and authorisation moves to the moment of use: "Per-document ACLs enforced at retrieval time, not only at storage." A permission checked when a document was indexed is not a permission checked when it is retrieved into a prompt.

Logging: the default inverts. "Default to least-logging. Tokenize or redact sensitive content before it reaches observability platforms. Apply short TTLs to debug captures." The observability pipeline is itself a copy of the sensitive data.

Network: "Treat each MCP integration as a distinct trust zone", and "Enforce egress controls on agents and code interpreters." The integration, not the perimeter, is the unit of trust.

Compartmentalisation: "Isolate privileged vs non-privileged agents."

Compliance: "Maintain unlearning-readiness for erasure obligations" — an erasure obligation now has to be satisfiable against trained and derived artefacts, not only records.

WHY THE LIST TAKES THIS SHAPE. The document's stated reason is that the context window has no internal reference monitor, so controls cannot be enforced inside it, and its corollary is that "every GenAI data security program must assume that any content reaching the model can influence any output". Everything above is therefore positioned as working around that problem rather than solving it, and the document says so.

WHAT THIS DOES NOT MEAN. These are additions, not replacements: the row is "the traditional control plus this", and dropping the conventional control because the GenAI-specific one is in place inverts the intent. The incident-response scenarios the same section names — output leakage, RAG poisoning, agent credential abuse, vector store compromise, disinformation campaigns — are the shapes these controls are meant to bound, not an exhaustive threat list.
