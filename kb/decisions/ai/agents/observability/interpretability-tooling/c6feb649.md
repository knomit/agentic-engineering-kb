# When the question is why a model produced a given output, no activation-reading tool beat simply reading the transcript — the tools name the features and the behaviour but almost never the link between them

A pipeline called CHIVE tested whether interpretability tooling helps an investigating model explain a target model's behaviour, against the cheapest possible baseline: reading the transcript. The stages are sampling 30 responses per prompt from the target, screening them with an investigator model for unexpected behaviour, running 5-15 counterfactual experiments per behaviour by editing the prompt, and scoring explanation quality with an independent judge. The measured quantity is whether the investigator correctly predicts that a given prompt edit will change the behaviour.

THE RESULT: "No tool beats the transcript-only baseline." Activation oracles, natural-language autoencoders and sparse autoencoders were each given "5 read-only calls on the target model's activations" and none improved on an investigator that only read the transcript. The stated mechanism is the part to carry away: tool outputs describe both the features and the behaviours that are already visible in the transcript, but "almost never explicitly state the causal relationship between them". The tool reports what is present; the causal step, which is the whole question, is left to the reader either way.

WHAT DID WORK: training models on counterfactual-prediction data improved substantially over the base models and generalised to held-out settings. The gap is in the predictor's training, not in the instrument.

OPERATIONAL CONSEQUENCE for anyone debugging an agent: establish the transcript-reading baseline before adopting or building activation-level tooling, and require the tooling to beat it on a prediction task rather than on how interpretable its output looks. The source's own methodological complaint is that most published system-card investigations lack a "transcript-reading reference" comparison, so an impressive-sounding interpretability finding may never have been measured against free.

SCOPE, AND WHAT THIS IS NOT. The predictor was Claude Opus 4.8; the targets were Gemma, Qwen3-8B and Qwen3.5-397B-A17B. This is not a claim that activation-level interpretability is useless — it is a null result on one task, counterfactual outcome prediction, with limits the source names itself: ground truth came from sampling the target, which real cases do not allow; and the behaviours the pipeline discovered are "fairly simple" next to the ones in system cards, so the harder cases are untested.
