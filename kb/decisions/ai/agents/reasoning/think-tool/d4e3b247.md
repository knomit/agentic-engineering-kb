# Anthropic now recommends extended thinking INSTEAD of a dedicated 'think' tool — and most of the tool's original measured gain came from the prompt anyway

SUPERSEDED BY ITS OWN SOURCE — checked 2026-07-27. The Anthropic article that introduced the think tool (published 2025-03-20) now carries an update notice dated 2025-12-15 stating that extended thinking capabilities have improved since the tool's initial release, such that they recommend using EXTENDED THINKING instead of a dedicated think tool in most cases. Treat 'add a think tool' as outdated default advice; reach for extended thinking first.

The original mechanics, still accurate and still the reason the two differ: the think tool is a tool that does nothing — calling it just appends the model's reasoning to the transcript. It differs from extended thinking by WHEN it fires. Extended thinking happens before generation begins; the think tool creates a reasoning step in the MIDDLE of a tool-use loop, giving the model a scratchpad for information it only discovered mid-run. That mid-loop niche is the only remaining argument for it, and improved extended thinking has largely absorbed it.

The measured results, on tau-bench airline with CLAUDE 3.7 SONNET (the evaluated model; a footnote adds that Claude 3.5 Sonnet (New) achieved gains with the same configuration):
- baseline 0.370
- think tool alone 0.404
- extended thinking 0.412
- think tool WITH a domain-optimised prompt containing worked examples 0.570

The headline '54% improvement' is the last line against the first. But the tool alone bought 0.034 and was slightly WORSE than extended thinking even at the time; the prompt bought the rest. The honest reading, and the part that survives the deprecation: a scratchpad tool is a place to put domain reasoning instructions, and the INSTRUCTIONS are doing the work. If you got a win from adding a think tool, test whether you keep it by moving those instructions into the system prompt and turning the tool off.

On tau-bench retail the effect was much smaller (0.783 baseline to 0.812). On SWE-bench the isolated effect was 1.6% on average — small but statistically significant at p < .001 — contributing to Claude 3.7 Sonnet's then-state-of-the-art 0.623.

The conditions remain the durable content. It helped on: long sequential chains of tool calls where errors compound, policy-heavy environments with detailed compliance rules to check against, and cases needing careful analysis of tool output before the next step. It did NOT help on: non-sequential or parallel tool calls, and simple instruction-following with few constraints — there you pay tokens and latency for nothing.

VERSION CAVEAT: figures are pass^1 on the 2024-era tau-bench against Claude 3.7 Sonnet, several model generations behind current releases (Opus 5 shipped 2026-07-24). The absolute values are superseded; re-measure before quoting any magnitude.
