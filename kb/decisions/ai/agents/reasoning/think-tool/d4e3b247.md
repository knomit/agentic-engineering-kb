# A no-op 'think' tool helps only on sequential, policy-heavy tool chains — and most of its measured gain came from the prompt, not the tool

The think tool is a tool that does nothing: calling it just appends the model's reasoning to the transcript. Mechanically it differs from extended thinking by WHEN it fires — extended thinking happens before generation begins, while the think tool creates a reasoning step in the middle of a tool-use loop, giving the model a scratchpad for information it only discovered mid-run.

The measured results on tau-bench airline, and the reason to read them carefully:
- baseline 0.370
- think tool alone 0.404
- extended thinking 0.412
- think tool WITH a domain-optimised prompt containing worked examples 0.570

The headline '54% improvement' is the last line against the first. But the tool alone bought 0.034 and was slightly WORSE than extended thinking; the prompt bought the rest. The honest reading is that a scratchpad tool is a place to put domain reasoning instructions, and the instructions are doing the work. On tau-bench retail the effect was much smaller (0.783 baseline to 0.812), and on SWE-bench the isolated effect was 1.6% — small but statistically significant at p < .001.

When it helps: long sequential chains of tool calls where errors compound, policy-heavy environments with detailed compliance rules to check against, and cases needing careful analysis of tool output before the next step.

When it does NOT help, stated explicitly: non-sequential or parallel tool calls, and simple instruction-following with few constraints. In those cases you are paying tokens and latency for nothing.

VERSION CAVEAT: published March 2025 against then-current Claude models, and the numbers are pass^1 on the 2024-era tau-bench whose absolute values are superseded. Treat the ranking and the conditions as the durable content and re-measure the magnitudes on current models before relying on them — later models do more of this reasoning natively, which should shrink the tool-alone delta further.
