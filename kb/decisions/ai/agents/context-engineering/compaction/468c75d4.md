# Compaction is an investment with a payback period of about ten turns, so compact before a break and never just before you finish

Compacting a conversation costs a fresh cache write over the rewritten history, and then pays that back through cheaper turns. Anthropic's cost guide for Claude Opus 5.5 puts a rough price on compacting at 150K tokens at about $0.25, with each later turn saving about $0.025, so it pays for itself within about ten turns.

Two consequences follow, and they point the same way. Compacting just before you finish a task costs more than it saves, because the turns that would repay it never happen. And compaction placed after a break during which the cache expired is far more expensive than the same compaction placed before that break: the input it has to process is no longer coming from cache, which at 150K context brings it to about $0.75 instead of about $0.25. So compact before a break, not after one — and if a session is nearly over, do not compact at all.

This does not mean compaction is a cost optimisation in its own right. It is a context-window measure whose bill happens to amortise; the decision of whether to compact at all is about what the model needs to still be able to see, and the payback period only tells you when to do it.
