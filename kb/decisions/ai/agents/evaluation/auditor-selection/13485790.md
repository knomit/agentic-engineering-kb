# A Haiku-class auditor finetuned on a planted-behaviour environment reached 72.7 audit quality against the Opus-class auditor's 68.0 and transferred to a second scaffold — so role-specific training is a live alternative to buying frontier capability for the auditor seat

The measurement. "After finetuning Haiku 4.5 on this environment, it matches Opus 4.6 on held-out evaluations for auditing quality." The reported numbers for the best configuration: "Audit quality reaches 72.7 (Opus 4.6: 68.0)", false positive calibration "holds at 99.6", and "realism climbs from 4.6 to 14.0 (Opus 4.6: 13.1)". Error bars are 95% confidence intervals across seeds, with three rollouts averaged per seed.

The generalisation evidence, which is what makes this a decision rather than a score. The trained auditor "transfers to AuditBench's fine-tuned targets in the Claude Code scaffold" — a harder target set, produced by finetuning rather than by system-prompt planting, inside a different harness from the one it was trained in. A within-distribution score alone would not support putting a trained small model in the auditor seat; a transfer to a different scaffold and a different target construction is the evidence that it is doing auditing rather than fitting the training environment.

THE DECISION THIS BEARS ON. When an agent occupies a narrow, repeated role — auditor, reviewer, triager, grader — the default move is to put the strongest available model in it, because the role looks like it needs judgement. This is one measured case where a cheap model trained on a purpose-built environment for that role beat the frontier model on the role's own metric. The condition under which that is available is visible in the setup: the role has to admit an environment where correct answers can be constructed (here, behaviours planted deliberately so that ground truth is known) and a reward that survives contact with the policy (see [[ed604adf]]).

CAVEATS THAT CHANGE HOW FAR THE NUMBERS CARRY. The metrics, the held-out suite and the judge are all the authors' own, and this is a single task family. Realism was not independently optimised in the training objective, so its rise is a side effect rather than a result. The realism figure is reported on a scale the post does not define; only the comparison against Opus 4.6 at 13.1 is usable from it, not the absolute value — for how the pack's realism-win-rate measurements are constructed and why an isolated realism number needs a baseline, see [[b84c73e8]].

What this does not mean: not that a small model matches a frontier model in general, and not that the auditing role is easy. The claim is bounded to an auditor trained in a purpose-built environment, measured on that environment's held-out split plus one transfer set.
