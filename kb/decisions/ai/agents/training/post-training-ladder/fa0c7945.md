# Five rungs for post-training an agent, each with the thing it structurally cannot teach — SFT never shows the model its own mistakes, distillation caps at the teacher, a reward function scores one turn — so the last rung trains through the harness the agent will actually run in

Hugging Face's published curriculum for post-training agents orders five methods, and the useful part is not the order but what each rung cannot do.

1. SFT on agent traces from a stronger model (`SFTTrainer`): needs a trace dataset. The limit is structural — "The model only sees correct traces, never its own attempts" — so it never learns to recover from its own mistakes, which is most of what a long agent run consists of.
2. Distillation from a teacher's tokens or probabilities (`DistillationTrainer`): needs prompts and a teacher. "the student is limited by what the teacher knows", and on-policy distillation additionally requires running the teacher at every training step.
3. RL with a reward function, GRPO (`GRPOTrainer`): needs prompts and a reward function. The signal is weaker than distillation's, "so the model needs many attempts to learn", and a plain reward function scores each answer once, as a single turn.
4. RL in an environment (`GRPOTrainer` with OpenEnv): needs tasks and an environment. Environments run tools, keep state and check results — for example by running tests — so the model can act over several turns. The price is a new bottleneck: "Each episode is longer than a single answer, so generating rollouts becomes the slowest part of training."
5. RL through a real agent harness at scale (`AsyncGRPOTrainer`): needs tasks, an environment and the harness. The rationale is the whole point of the ladder — "Training through the same harness the agent uses in practice means the model learns in the setting where it will run."

THE ENGINEERING CONSEQUENCE OF RUNG 4's BOTTLENECK is stated: "Generation and training run on separate GPUs, so long episodes don't leave the trainer idle", with updated weights sent back to the inference server. Plan for that split before rollouts become the critical path, not after.

WHAT THIS DOES NOT MEAN. The ladder is not a claim that each rung beats the one below it on any benchmark — the source reports no accuracy gains, training costs or benchmark results, and gives no rationale for the ordering beyond the sequence of the livestream series it accompanies. Treat it as a map of each method's input requirements and blind spot, not as evidence that harness-level RL is worth its cost for your case. Hardware, sandbox provider and minimum resources are not stated.
